# 📄Rabin-Karp Algorithm: In-depth Analysis and Implementation
This repository contains an in-depth research report and implementation of the Rabin–Karp string-matching algorithm. The project explores the mechanics of rolling hashes, compares Rabin–Karp with other classic string-matching algorithms, analyzes time complexity, and provides detailed examples and code explanations.

# 🔍 Overview

The project breaks down the Rabin–Karp algorithm from both a theoretical and practical perspective:

* Explains how rolling hash functions work
* Shows step-by-step pattern matching examples
* Demonstrates the algorithm with sample Python code
* Compares Rabin–Karp to Naive, Boyer–Moore, and KMP algorithms
* Analyzes best-, average-, and worst-case complexity
* Discusses real-world applications such as plagiarism detection and bioinformatics
